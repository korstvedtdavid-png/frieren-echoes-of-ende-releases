# Frieren: Echoes of Ende

An unofficial, non-canon fan project. **Early Windows development build, v0.1.0-dev.**

## Download and launch

[Download the Windows release](https://github.com/korstvedtdavid-png/frieren-echoes-of-ende-releases/releases/tag/v0.1.0-dev).

1. Download `FrierenEchoesOfEnde-v0.1.0-dev-Windows.zip` under **Assets**.
2. Extract the entire ZIP.
3. Open `Windows/EchoesOfEnde.exe`. Keep the adjacent `Engine` and `EchoesOfEnde` folders together.
4. Choose mage with **1** or warrior with **2**, then press **Enter**.

Unreal Editor is not required. This build targets 64-bit Windows and DirectX 12 / Shader Model 6 graphics. Managed PCs may require administrator approval for the unsigned executable; downloading from GitHub does not change that requirement.

## Development status

Includes a procedural valley, mage and warrior controls, combat encounters, an original village-to-ruin quest, a companion, inventory, and save/load systems. Art, animation and synthesized audio are pre-production placeholders.

**Native compilation and packaging succeeded. Gameplay, performance and automated tests have not been runtime-validated. This is an unfinished development foundation; no successful gameplay launch is claimed.**

## Controls

WASD / mouse: move / look. Space: jump. Shift: sprint. Left Ctrl: dodge. Left / right mouse: attack / guard. Hold and release Q: charged attack. F: interact. E: mana sense. C: lock target. R: restorative. M: map. Tab: inventory. Escape: pause. F5 / F9: save / load.

Controls are implemented and await runtime verification. Follow the road north through training, speak with the caretaker, explore the ruin, and return to the village memorial.
